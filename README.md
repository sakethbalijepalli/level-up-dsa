# Level Up DSA

**Level Up DSA** is a Claude skill for solving LeetCode and HackerRank Online Assessment (OA) coding interview problems with optimized solutions, platform-specific code (function stubs or custom I/O), and step-by-step explanations.

## Owner

**Saketh Balijepalli** ([GitHub](https://github.com/sakethbalijepalli/))

## Features

When given a coding problem, this skill guides the agent to provide:
- **Problem Understanding**: Plain-language distillation of constraints and story descriptions.
- **Brute Force & Paper-and-Pen Breakdown**: Step-by-step breakdown as if solving on paper.
- **Optimized Solution**: Best time/space algorithm with clean, platform-ready code in your preferred language (LeetCode `class Solution`, HackerRank `class Result`, or standard I/O).
- **Deep Explanations**: Line-by-line breakdown, dry-run table, complexity analysis, and edge case coverage (hidden test cases, overflow, TLE).
- **Optimization Summary**: Comparison showing why the optimized approach outperforms brute force.

## Files

- [`SKILL.md`](SKILL.md): Skill metadata, pattern directory, and core instructions.
- [`AGENTS.md`](AGENTS.md): Detailed agent execution rules, formatting standards, and full examples.

## Usage

Paste a LeetCode or HackerRank OA problem and request a solution or approach.
